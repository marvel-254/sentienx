## TROUBLESHOOTING

### Dashboard Won't Load
1. Check port 8501 is free: `lsof -i :8501`
2. Restart: Kill process and restart
3. Check logs: `cat /tmp/dashboard.log`

### No Data Showing
1. Ensure trading bot is running
2. Check database exists: `ls -la sentienx_trading.db`
3. Execute some trades to populate data

### Slow Performance
1. Increase refresh interval in sidebar
2. Filter data (fewer trades to display)
3. Reduce chart complexity

### API Not Responding
1. Check API running on 8080: `lsof -i :8080`
2. Verify Deriv credentials in .env
3. Check .env file not empty
