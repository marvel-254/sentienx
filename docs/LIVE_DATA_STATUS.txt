RUNNING BOTH SERVICES
====================

Option 1 - Two Terminal Windows:
# Terminal 1:
cd /sentienx && python3 api_server.py

# Terminal 2:
cd /sentienx && python3 -m streamlit run dashboard/unified_dashboard.py --server.port=8501

Option 2 - Background Processes:
# Run both in background
cd /sentienx
python3 api_server.py > /tmp/api.log 2>&1 &
python3 -m streamlit run dashboard/unified_dashboard.py --server.port=8501 > /tmp/dashboard.log 2>&1 &

Option 3 - Using Scripts:
./start_api.sh      # Starts API
./run.sh           # Starts Dashboard (in separate terminal)
